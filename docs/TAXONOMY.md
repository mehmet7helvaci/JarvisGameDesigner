# 🏷️ Bilgi Tabanı Taksonomisi ve Güvenilirlik Katmanları

## 1. Ana Kategoriler (MDA + Schell's Elements)

| Kategori Kodu | Açıklama |
|---|---|
| `core_mechanics` | Temel mekanikler, eylemler, Core loop |
| `game_systems` | Ekonomi, crafting, progression, skill tree |
| `game_balance` | Dengeleme, eğriler, meta-game, power curves |
| `controls_input` | Girdi yönetimi, gamepad, dokunmatik kontroller |
| `level_design` | Bölüm tasarımı, akış, tempo (pacing), flow |
| `ai_design` | Oyun yapay zekası, behavior tree, state machines |
| `multiplayer` | Çok oyunculu, ağ senkronizasyonu, co-op |
| `narrative` | Hikaye, diyalog, çevresel anlatı, lore |
| `ux_ui` | Arayüz tasarımı, HUD, diegetic UI, affordance |
| `audio_design` | Ses tasarımı, dinamik müzik, SFX, foley |
| `visual_design` | Sanat yönetimi, renk teorisi, görsel netlik |
| `player_psychology`| Motivasyon, bağlılık, dopamin döngüleri |
| `player_types` | Bartle taksonomisi, oyuncu profilleri |
| `accessibility` | Erişilebilirlik, renk körü modları, remapping |
| `monetization` | F2P, battle pass, premium, mikro ödemeler |
| `market_analysis` | Pazar trendleri, Steam verileri, rekabet |
| `analytics` | KPI'lar, retention, churn, metrikler |
| `gdd` | Game Design Document şablonları ve pitchler |
| `prototyping` | Prototipleme, playtest, grayboxing |
| `postmortem` | Proje sonrası analizler ve öğrenilen dersler |
